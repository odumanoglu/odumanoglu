## Merhaba, Ben Oğuzhan 👋

Kastamonu Üniversitesi Bilgisayar Programcılığı bölümünde öğrenim görüyorum. Yazılım geliştirme sürecinde özellikle veri bilimi, 2D oyun geliştirme ve web teknolojileri üzerine çalışıyorum. 

###  Teknolojiler & Araçlar
- **Diller:** C#, Python, SQL, HTML/CSS
- **Oyun Geliştirme:** Unity (2D Physics, Collision, Camera Tracking), Blender, Adobe Animate
- **Veri Bilimi & ML:** Pandas, NumPy, Scikit-learn, XGBoost, Random Forest
- **Veritabanı:** SQL Server Management Studio

###  Üzerinde Çalıştığım Odak Alanları
- Sağlık verileri üzerinde makine öğrenmesi ile sınıflandırma modelleri geliştirmek.
- C# scriptleri ile Unity üzerinde dinamik 2D oyun mekanikleri tasarlamak.
- Flexbox ve modern CSS mimarileri ile duyarlı (responsive) web arayüzleri kodlamak.
