## 👨‍💻 About Me

My work focuses on object-oriented programming, game development, data science, and web technologies.

- 🎮 **Game Development:** I design 2D game prototypes (character mechanics, tilemap design, collision detection) with Unity and C#.
- 📊 **Data Science & Machine Learning:** I build classification models and run data analyses with Python (Pandas, scikit-learn), such as Alzheimer's disease classification.
- 🌐 **Software & Web:** I work with C# and the .NET ecosystem, and build local server-based web interfaces using HTML, CSS, and PHP, with SQL Server for databases.
- 🚀 **Project Development:** I develop concept projects (e.g., a smart food assistant) and write technical documentation for Teknofest's Healthcare AI category.
